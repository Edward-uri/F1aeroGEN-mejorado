# Patrón de Resultados (Results)

Visualización de datos de salida del algoritmo genético.

- **Stats Grid**: Tarjetas individuales con borde izquierdo acentuado (`4px solid var(--accent)`).
- **Valores**: Tipografía `Chakra Petch` con tamaño `2rem` o superior para datos clave.
- **Diferenciales**: Insignias (`diff-badge`) con fondo semitransparente (`0.15 opacity`) y flechas de tendencia.
- **Tablas**: Diseño moderno sin bordes laterales, filas con hover sutil.
