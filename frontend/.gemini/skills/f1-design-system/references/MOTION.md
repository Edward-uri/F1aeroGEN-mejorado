# Guía de Animación (Motion)

Uso de `framer-motion` para todas las transiciones.

- **Transición de Páginas**: Fade + Slide lateral (`x: 20 -> 0`) con `duration: 0.4`.
- **Listas de Tarjetas**: Animación escalonada (`staggerChildren`) para una entrada tipo "cascada".
- **Feedback de Botones**: Escala `0.98` en click y `1.02` en hover ligero.
